Artisan Guilds (formerly MSGuilds) lets players create guilds, invite members, give them ranks with
permissions, share a bank, a home and a chest, chat between members and allies, and level the guild up.
The menus are Artisan menus, edited in the editor. With ArtisanGuildQuests, guilds get quests of their own.

## Requirements

| | |
|---|---|
| Server | Paper 1.21 or newer (not Folia) |
| Java | 21 |
| Artisan | API 1.0.0 or newer (Artisan 1.0.0) |
| Optional | Vault and an economy plugin (the guild bank); Core, only for the one-time import from MSGuilds |
| ArtisanGuildQuests | Needs Artisan Quests and Artisan Guilds |
